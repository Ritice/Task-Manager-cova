# Task Manager - MonoRepo

Projet complet de gestion de tâches (*Task Manager*) comprenant une API REST backend développée avec **Spring Boot 3** 
et une interface utilisateur web moderne construite avec **React 19 + Vite**.

---

## Structure du MonoRepo

```text
Task Manager/
├── task-manager-backend/    # Application API REST Spring Boot 3
├── task-manager-frontend/   # Application Web React 19 + Vite + TypeScript
├── docker-compose.yml       # Orchestration des conteneurs (App + MySQL)
├── .gitignore               # Règles d'exclusion Git globales
└── README.md                # Documentation principale du projet
